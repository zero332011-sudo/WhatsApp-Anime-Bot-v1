# WhatsApp Anime Bot

بوت واتساب عربي باستخدام Baileys وNode.js 20 أو أحدث.

## التشغيل
1. ارفع الملفات إلى GitHub.
2. على استضافة Node.js انسخ `.env.example` إلى `.env` وضع رقم واتساب البوت والمطور.
3. نفّذ `npm install` ثم `npm start`.
4. اقرأ رمز الربط من سجلّات الاستضافة، ثم واتساب > الأجهزة المرتبطة > ربط جهاز برقم الهاتف.
5. لا ترفع `.env` أو مجلد `auth_info_baileys` إلى GitHub.

## ملاحظات
- أضف صور لعبة التخمين يدويًا داخل `anime/images/` وسمِّ كل صورة باسم الشخصية، مثل `غوكو.jpg` أو `ناروتو.png`.
- الكتم هنا يمنع البوت من التعامل مع رسائل العضو خلال المدة؛ لا يمنع واتساب نفسه من إرسال الرسالة. قفل المجموعة يتطلب أن يكون البوت مشرفًا.
- استخدم الاستضافة التي تسمح بعملية Node.js دائمة وتخزين ملفات دائم. لا توجد استضافة مجانية مضمونة 24/7 بلا قيود.
- احترم حقوق نشر الأنمي، ولا ترفع أو توزع حلقات لا تملك حق نشرها.

## تحديث لعبة خمن والمشاركة
- كل جولة مدتها 30 ثانية. عند انتهاء الوقت يعلن البوت اسم الشخصية ثم يرسل صورة جديدة تلقائيًا ويبدأ عداد 30 ثانية من جديد.
- للانضمام اكتب `تم` أثناء اللعبة. ويمكن لصاحب اللعبة إضافة عضو باستخدام `.مشارك @العضو` أو بالرد على رسالته بالأمر `.مشارك`.
- الإجابة الصحيحة تُمنح لأول مشارك يكتب الاسم، ويحصل على 20 جنيه في البنك.
- أسماء الصور تُطابق الإجابة بعد توحيد بعض أشكال الحروف العربية؛ استخدم اسم الشخصية بالعربية في اسم الملف.
